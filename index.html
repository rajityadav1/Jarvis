AI provider API key

Not entered here. Your AI provider key belongs on your backend as a secret. Anything saved in a web page can be read by browser extensions and by anyone holding your phone. The access token above is only a passcode for your own backend, not your provider key.

Voice

Limits you should know

No always-on listening. JARVIS hears you only while this page is open and you have tapped the mic. A web page cannot listen for "Hey JARVIS" in the background, with the screen off or with the phone locked.

On Chrome for Android, speech recognition usually sends your audio to Google's speech service, so it needs an internet connection.

Connect a backend securely

Setup steps (free to start)

The interface is free. The AI itself needs an account with an AI provider, which usually bills per use. A small backend keeps that provider key off your phone.

  1. Host this page on a free HTTPS static host such as GitHub Pages or Cloudflare Pages. Voice input will not work from a plain file or an http address.
  2. Create a Cloudflare Worker (free plan) and paste in the code below.
  3. Store two secrets on the Worker: AI_API_KEY (your provider key) and APP_TOKEN (a long random passcode you invent).
  4. Set two plain variables: ALLOWED_ORIGIN (the address of the page you hosted in step 1) and MODEL (a model ID from your provider's docs).
  5. Paste the Worker's URL and your APP_TOKEN into the fields above, then press Test connection.

With the Wrangler command line, step 3 looks like this:

npx wrangler secret put AI_API_KEY
npx wrangler secret put APP_TOKEN
